# Aroma Cake Shop

An interactive visual study where a scent becomes a patisserie world. Choose Strawberry, Chocolate, or Apple, watch the source ingredient compress into artistic scent particles, then enter its distinct cake-shop interior.

## Tech stack

- Semantic HTML
- CSS (responsive Rococo-inspired illustration and transitions)
- Vanilla JavaScript (screen state, interaction locking, and Canvas particles)

## Run locally

This MVP has no dependency or build step. Open `index.html` in a current desktop browser, or serve the folder with any static server. For example, from PowerShell with Python installed:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Interaction flow

1. Select **Enter the Shop** on the start screen.
2. Pick Strawberry, Chocolate, or Apple.
3. The selected ingredient is compressed, becomes scent particles, and opens its matching patisserie.
4. Use the scent menu to switch scenes or choose **Back to Scents** to replay the discovery interaction.

## Deployment

This is a static site. It can be deployed as-is to GitHub Pages, Netlify, or Vercel without a build command; publish the repository root as the site directory.
